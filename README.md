# IBM Data Science Capstone — SpaceX Falcon 9

Applied Data Science Capstone (IBM Data Science Professional Certificate) by Dong Minh Duong.

This repository contains the SpaceX Falcon 9 first-stage landing prediction notebooks and datasets from the capstone lab work.

## Contents

- `jupyter-labs-spacex-data-collection-api.ipynb` — Module 1: Data Collection via the SpaceX API
- `jupyter-labs-webscraping.ipynb` — Module 1: Web Scraping
- `labs-jupyter-spacex-Data_wrangling.ipynb` — Module 1: Data Wrangling
- `jupyter-labs-eda-sql-coursera_sqllite.ipynb` — Module 2: Exploratory Data Analysis with SQL
- `dataset_part_1.csv`, `dataset_part_2.csv`, `dataset_part_3.csv` — Capstone datasets (90 rows each)

## Note

The notebooks included here are the ones present in the Skills Network lab workspace for this capstone. The Module 2 data-visualization, Module 3 (Folium / Plotly Dash), and Module 4 (Machine Learning Prediction) notebooks were completed earlier in a different lab environment and are not in this repository; their results are summarised in the capstone presentation PDF submitted for the course.
